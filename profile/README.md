# TierArc

**One basket. Twenty digital assets. Auto-rebalancing by design.**

TierArc is building a transparent, auto-rebalancing crypto basket protocol designed to simplify access to twenty digital assets through one experience.

## Launch status

- **Phase:** Public testing
- **Target launch:** January 12, 2027
- **Network focus:** BNB Chain
- **Early access:** [TierArc.com](https://tierarc.com)

> **Testing notice:** No live token sale is active. Values displayed in the current experience are simulated unless explicitly labeled otherwise.

## Learn how crypto baskets work

Explore TierArc's educational guide to [crypto basket protocol fundamentals](https://tierarc.com/learn), including basket construction, issuance and redemption, pricing and oracle concepts, rebalancing, verification steps, and key risks.
